# Satellite domain

Raster, calibration, registration, geospatial, atmosphere, spectral, temporal, and harmonic methods belong here. Spherical harmonics and spectral/geospatial processing must not be placed in generic document code.

MP4 registers `satellite` only as a geospatial-reconstruction DomainPack stub. It does not implement raster calibration, coordinate-reference systems, atmospheric correction, or spectral/harmonic algorithms.
