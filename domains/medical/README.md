# Medical research domain

This is research infrastructure only. It is not diagnostic medical-device software and must not be represented as clinical advice, validation, or regulatory clearance. Future DICOM, registration, segmentation, reconstruction, volume, and measurement modules must be separately governed.

MP4 registers `medical_research` only as a volumetric-reconstruction DomainPack stub. That registration is an interface compatibility check, not a medical-image algorithm, validation result, or diagnostic claim.
