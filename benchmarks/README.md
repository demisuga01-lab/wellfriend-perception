# Benchmarks

Schemas cover quality, detection, fusion, reconstruction, restoration, OCR/semantic outcomes, latency, memory, and battery/device class. `schema/mp2-scalar-baseline.example.json` shows the generic baseline envelope. MP4 adds reconstruction dimensions/aspect/coverage/stretch fields and condition/router/restoration fields to the schema. See `docs/benchmark-format.md` for ScanBench policy and reproducibility expectations.
