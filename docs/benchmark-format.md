# Benchmark format

Each benchmark record is JSON or CSV with `schema_version`, sample identifier and hash, domain, runtime/device class, dependency/model versions, and explicit metric units. ScanBench for documents records quality scores, page coverage/visibility, detector candidate error, fusion diagnostics, corner and reconstruction error, restoration scores, semantic OCR metrics, latency, memory, and battery impact. Benchmarks must retain dataset provenance and must not redistribute restricted samples.
