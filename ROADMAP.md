# Roadmap

MP1 establishes contracts and baseline correctness. MP2 adds generic image/math/geometry foundations; MP3 adds document perception intelligence; MP4 adds canonical reconstruction, routing, scalar restoration, and executable DomainPack registration. Later milestones add audited model integration, curved-page reconstruction, semantics/OCR, export, portable bindings, and governed benchmarks. Medical support remains research-only unless a separate regulated-product program is approved.
